# NexusChat - AI Assistant

NexusChat is a free AI assistant web application built with Next.js, MongoDB, and the Gemini API. It allows users to chat with an AI assistant, upload images for analysis, and save conversation history.

## Features

- User authentication (signup, login, logout)
- Chat with AI assistant
- Upload and analyze images
- Save and manage conversation history
- Dark/light mode toggle
- Responsive design

## Tech Stack

- **Frontend**: Next.js, React, Tailwind CSS, shadcn/ui
- **Backend**: Next.js API routes
- **Database**: MongoDB
- **Authentication**: JWT
- **AI**: Google Gemini API
